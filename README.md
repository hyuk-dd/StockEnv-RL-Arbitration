# 📊 인간 동적 의사결정 원리를 활용한 강화학습 기반 주식 시장 적응형 앙상블 모델
### 🔎 연구 배경
앙상블 기반 강화학습 모델은 주식 시장에서 **포지션 선택**과 **자산 배분** 문제에서 우수한 성능을 보입니다.

그러나 이러한 알고리즘은 검증 단계의 기간 동안 우수한 성능을 보이는 모델을 이후 기간에 활용하는 방식이기 때문에, 실제 시장의 환경 변화에 **동적으로 대응하기 어렵습니다.**

따라서 환경 변화에 따라 전략을 동적으로 조정할 수 있는 **적응성(adaptivity)** 을 반영한 모델의 설계가 필요합니다. \
이러한 적응성은 **인간의 의사결정 체계의 특성**으로 신경과학 연구에서는 이를 베이지안 사후 확률에 기반한 신뢰도 추정을 통해 **Model-based**와 **Model-free** 시스템 간의 전환으로 설명합니다.

본 연구는 이러한 인간의 동적 의사결정 원리를 차용하여, 강화학습 모델 간 신뢰도를 기반으로 의사결정을 조정하는 **적응형 앙상블 모델**을 탐구합니다. 탐구한 모델을 한국, 일본, 중국 시장에서 기존 방식 대비 누적 수익률과 Sharpe Ratio 측면에서 성능을 평가해 시장 환경에 따라 의사결정을 유연하게 조정할 수 있는지 평가하고자 했습니다.
